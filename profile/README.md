# Embird

> One named Embird design. Finish the stitch pass. Leave a note the next person can read.

## How Embird Sits

Embird does not replace the sewing machine, the hoop, or the stitch files you already own. It sits beside them as a named machine desk for one job: which embroidery file is live, which lettering still fits, and what the next person should read before the next sew.

If two people share a sew PC, each keeps an Embird style of their own. Extra hoops wait for their own title instead of crowding the live design.

A first visit should be one short stitch edit, then the same Embird desk the next day. That is enough to see if the layout holds.

## Traffic Light

| Signal | On the Embird board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live design list | Continue the same stitch file |
| Amber | Two hoops mixed in one editor | Split the set before lettering |
| Red | No title, no note, stitches unlabeled | Stop and name the design first |
| Clear | Handoff written, live files few | Close Embird and leave the desk |

## Open Order

1. Open the last Embird design, not a new empty machine desk.
2. Read the stitch list and the last handoff.
3. Finish one visible lettering pass inside Embird.
4. Write what changed, then close with fewer unlabeled files than you found.
5. If the set feels crowded, drop anything that belongs to a different Embird hoop.
6. Confirm Embird lettering still sits on the stitch file you own.

## Desk Fit

| Who | What Embird holds |
|-----|--------------------|
| Sew desk | Stitch files and lettering for a machine you own |
| Shared desk | One Embird profile per person |
| Home hoop | Personal designs out of the work sew pile |
| Shop | Named embroidery files waiting for the next sew |
| Support | A repeatable Embird layout for the same machine |

## After a Week

A week in Embird is not a bigger hoop pile. It is the same title, a shorter live design list, and a note that still makes sense before thread goes in. Take finished files off the live set so the next visit starts on the stitch set that is still open.

Other programs stay where they are. Embird only keeps the path back: desk name, stitch editor, lettering, handoff.

Leave Embird with a quieter machine desk than the one you opened. The next visit should start on that design, not in a guess inside the hoop.

## Sign-off

- [ ] The Embird workspace name is short enough to scan
- [ ] Only the live design is on the board
- [ ] A second person can read the handoff
- [ ] The last Embird file still opens after a restart
- [ ] Finished hoops are off the live Embird set
- [ ] The Embird summary still matches the stitch list

## Field Note

Embird is easier to trust when the machine desk stays smaller than the hoop folder it came from. Name the design, keep the live stitch file, finish one visible lettering pass, and write what changed.
